집계 규칙:

- `Valid final TICA hit (%)` = (최종 frame 이 hit **이고** whole-path QC 통과) 경로 수 / **전체 반환 경로 수**.
  invalid 경로를 분모에서 제외하지 않았다.
- `Weighted valid-hit mass (%)` = 같은 조건을 만족한 경로의 정규화 outer weight 합.
  QC 로 거른 뒤 weight 를 재정규화하지 않았다.
- 두 값은 서로 다른 양이며 TPS-DPS 의 THP 와도 다른 정의다.
- `Final TICA d/d₀`, `Final backbone RMSD`, `Final native-contact Q` 는 weight 가중 평균이다.
- native contact 정의는 전 단백질 공통: folded target 에서 공통 heavy-atom 최소거리 < 4.5 Å
  이고 sequence separation ≥ 3 인 잔기쌍을 native pair 로 두고, 생성 구조에서 같은 쌍의
  최소거리가 참조 거리의 1.2배 이하이면 형성으로 센다.
- whole-path QC = 경로의 모든 frame 이 좌표 유한성, 비인접 Cα ≥ 1.0 Å,
  인접 Cα ≤ 5.501 Å, peptide C–N ∈ [1.0, 1.7] Å 를 통과.

## 4. 기록하지 않은 항목

명세에 있으나 이번 집계에 포함하지 않은 것:

| 항목 | 상태 |
| --- | --- |
| TICA 좌표 (TIC1, TIC2) 자체 | run 디렉토리에는 미저장. 본 문서의 거리는 저장된 atom37 population 을 동일 변환기로 재투영해 계산 |
| heavy-atom RMSD | 미계산 |
| contact map 전체, secondary structure | 명세상 이번 benchmark 제외 |
| chirality inversion count | 미계산 |
| force-field potential energy, ETS | 명세상 이번 benchmark 제외 |
| 경로 다양성 / reference pathway fidelity | 미계산 |
| Outer-only, Inner-only 추가 baseline | 미실행 |

`metrics.json` 의 `per_path_final_d_a` 와 `weighted_mean_final_d_over_d0` 는 potential 이
TICA 여도 평가 경로가 RMSD metric 을 사용하므로 backbone RMSD 다. 본 문서의 TICA 열은
저장 좌표에서 재투영한 값이고, backbone RMSD 열은 별도로 계산한 값이다.

`_launcher/state/failed_cells.tsv` 의 4행은 실제 실패가 아니다. 같은 디렉토리의
`failed_cells_NOTE.md` 참조.
