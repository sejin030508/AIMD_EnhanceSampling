## 1. 실험 설정

### 1.1 검정하려는 질문

선행 360셀 실험에서 DuET과 Complete Nested는 모든 지표에서 구분되지 않았다(|t| < 1.5).
두 방법은 K, M, 예산, reward, 시드가 동일하고 **안쪽(inner) resampling 여부만 다르다.**

Phase 0 진단에서 다음이 관측되었다.

- 안쪽 필터의 첫 체크포인트는 실제로 선택을 수행한다 (ESS/M ≈ 0.68–0.73)
- 바깥 필터는 32 전이 중 4.2–4.9회만 resampling을 발동한다
- 두 필터 모두 **같은 terminal reward**를 참조한다

여기서 나온 **가설**은 "바깥 필터가 곧 수행할 선택을 안쪽 필터가 먼저 수행하고 있어
추가 정보가 없다"는 것이었고, 그 **예측**은 다음과 같았다.

> **바깥 필터가 약하거나 없을수록 안쪽 필터의 상대적 가치가 커져야 한다.**
> 극단인 K=1에서는 바깥에 고를 대상이 없으므로 DuET이 Complete Nested를 이겨야 한다.

본 실험은 이 예측을 검정한다.

**중요한 한계 (설계 단계에서 이미 확인됨):** K=1에서도 Complete Nested는 여전히
**완성된 64개 후보 중 reward로 하나를 선택한다.** 즉 "outer를 끄면 DuET만 steering한다"가
아니다. 실제로 비교되는 것은 다음 둘이다.

```
K=1 Complete Nested : 후보 64개를 끝까지 생성 → reward로 선택
K=1 DuET            : 후보 64개를 diffusion 도중 선택·복제 → 최종 보정 후 선택
```

따라서 이 실험이 답하는 것은 정확히는:

> **M을 크게 확보한 상황에서 pre-completion resampling이
> complete-frame selection보다 유리해지는가?**

이고, **K와 M이 함께 변하므로 "outer를 껐기 때문"이라는 인과 귀속은 이 설계로 불가능하다.**

### 1.4 Reward·gate·지표 (선행 실험과 완전 동일)

```
log ψ_t = −16 · (d_RMSD(x_t, target) / d₀)²      # 공통 N/CA/C Kabsch RMSD
```

- 바깥 resampling `systematic`, ESS 임계 **0.5** / 안쪽 resampling `systematic`
- validity: 좌표 유한 + 비인접 CA ≥ 1.0 Å + 인접 CA ≤ 5.501 Å + 펩타이드 C–N ∈ [1.0, 1.7] Å
- 성공 조건: 첫 두 backbone-torsion TICA 좌표 거리 < 0.75 **및** 경로 전체 validity 통과

## 5. 해석

해석은 **관측**과 **가설**을 분리해 적는다. 인과 주장을 그대로 인용하지 말 것.

### 5.1 관측된 사실 (집계 방식과 무관)

**(1) 세 배분 어디에서도 DuET이 Complete Nested를 이기지 않는다.**
9건의 wBB 검정(3 단백질 × 3 배분)에서 DuET이 유의하게 나은 경우는 **0건**이다.
통합 효과크기는 K=1에서 g = +0.256 [−0.106, +0.619], K=2에서 +0.300 [−0.064, +0.664],
K=8에서 −0.128 [−0.486, +0.231]로, **세 구간 모두 95% CI가 0을 포함한다.**

**(2) 예측된 방향이 나타나지 않았다.**
가설은 K가 작아질수록 g가 음수 쪽으로 커질 것을 예측했다. 관측된 순서는
K=8 (−0.128) → K=2 (+0.300) → K=1 (+0.256)로 **예측과 반대 방향**이다.
K=1과 K=8의 통합 g 차이는 +0.384 (z = +1.48)로 유의하지 않지만, 부호가 가설과 반대다.

**(3) 안쪽 필터의 선택 압력은 M에 거의 무관하다.**
첫 체크포인트 ESS/M은 M = 64 / 32 / 8에서 Trp-cage 0.656 / 0.674 / 0.718,
BBA 0.660 / 0.626 / 0.680, BBL 0.833 / 0.839 / 0.861로 거의 변하지 않는다.
M을 8배로 늘려도 **가중치 분포의 균등성은 그대로**다.

**(4) 두 번째 체크포인트의 ESS/M은 M과 무관하게 0.993–0.996이다.**
`noop2`(항등 비율)는 M이 커질수록 크게 떨어지지만(0.797 → 0.339),
**이는 선택이 활발해졌다는 뜻이 아니다** — systematic resampling이 정확히 항등
순열을 반환할 확률은 M이 커지면 조합적으로 작아진다. ESS/M이 변하지 않았다는 것이
실질적 신호이고, `noop2` 감소는 그 조합적 부산물이다.

**(5) K를 줄이면 validity가 나빠진다.**
Trp-cage: K=8에서 0.99 → K=2, K=1에서 0.90. BBL: K=8에서 0.21–0.24 → K=1 CN에서 0.10.
바깥 resampling이 없으면 망가진 경로를 솎아낼 기전이 사라진다.

**(6) TICA 타깃 도달은 K가 작을수록 사라진다.**
Trp-cage·BBA는 K=1에서 DuET·CN 모두 hit 0이다. 전체 신규 240셀에서 hit은 6건에 불과하다.

### 5.2 경로 수에 의존해 K 간 비교가 불가능한 지표

다음은 K가 다르면 **비교 자체가 성립하지 않는다.** raw 표에는 그대로 실었으니
집계 시 반드시 구분할 것.

| 지표 | 이유 |
| --- | --- |
| `bestBB` | 경로 집합의 최솟값. K=8은 8경로 중 최선, K=1은 1경로. Trp-cage DuET 3.28(K=8) → 3.90(K=1)의 악화 대부분이 이 효과 |
| `TICAmin` | 동일 |
| `Qmax` | 동일. **K=1에서는 `Qmean`과 정의상 같은 값** |
| `hit/path` | 경로당 정규화라 형식상 비교 가능하나, 전체 hit이 6건이라 검정력이 없다 |

**K 간 비교에 쓸 수 있는 지표는 `wBB`, `Qmean`, `valid`**이며, 본 보고서의 결론은
모두 `wBB` 기준이다.

### 5.3 검정되지 않은 것 — "중복" 가설의 지위

Phase 0 문서는 DuET ≡ CN의 원인을 "안쪽 필터가 바깥 필터와 같은 reward를 먼저
적용하는 중복"으로 설명했다. **이 설명은 본 실험으로 확인되지 않았고, 그 예측도
지지되지 않았다.** 동시에 다음 이유로 **반증되었다고 볼 수도 없다.**

| 한계 | 내용 |
| --- | --- |
| **K와 M의 교락** | 두 값이 함께 변하므로 "바깥 필터 제거"의 효과를 분리할 수 없다 |
| **CN도 여전히 선택한다** | K=1 CN은 완성된 64후보 중 reward로 선택한다. "선택 기전이 DuET에만 있는" 조건이 아니다 |
| **outer update 식 미확인** | 실제 코드가 `W ∝ W · Ẑ/ψ(parent)`를 쓰는지, child reward를 재적용하는지 확인하지 않았다. telescoping 오차 0은 potential 곱의 상쇄만 보장한다 |
| **D2·D3 미측정** | 체크포인트 추정↔최종 결과 상관, 후보 간 구조적 spread를 측정하지 않았다 |
| **검정력** | 통합 g의 SE ≈ 0.185. |g| < 0.36 의 실제 효과는 이 표본으로 검출되지 않는다 |

현재 근거로 말할 수 있는 가장 정확한 진술은 다음이다.

> **예산 K·M = 64, T = 32, RMSD reward 조건에서, 바깥 입자 수를 1까지 줄여도
> pre-completion resampling(DuET)이 complete-frame selection(Complete Nested)보다
> 유리해지지 않았다.** 통합 효과크기는 |g| ≤ 0.30이며 95% CI가 0을 포함한다.

이는 **동등성의 증명이 아니다** — 비유의한 차이는 "차이 없음"이 아니라 "검출 실패"다.
동등성을 주장하려면 별도의 equivalence test(TOST 등)와 사전 정의된 동등성 한계가 필요하다.

### 5.4 대안 가설 (본 실험으로 배제되지 않음)

DuET ≡ CN을 설명할 수 있으면서 아직 검정되지 않은 것들:

1. **초기 latent가 endpoint를 대부분 결정한다.** 체크포인트에서 복제한 뒤의 SDE가
   목표 관련 구조 변화를 거의 추가하지 못하면, 중간 선택과 완성 후 선택이 같은 결과에
   도달한다. → 같은 체크포인트에서 분기한 자식들의 최종 구조 분산을 측정하면 직접 확인됨.
2. **Reward가 한 전이 내부의 구조 차이에 둔감하다.** 선행 진단에서 전이당 거리 변화폭은
   0.22–0.25 Å, 타깃까지 거리는 4.5–17 Å였다. → 체크포인트 추정값과 최종 RMSD의
   상관(D2)을 측정해야 한다.
3. **첫 체크포인트의 추정이 이미 충분히 정확하다.** 그렇다면 두 번째 체크포인트의
   높은 ESS는 실패가 아니라 "보정할 것이 없음"이다. ESS만으로는 이 경우와
   "후보가 축퇴됨"을 구분할 수 없다.

### 5.5 쓸 수 없는 표현

- ❌ "K를 줄이면 DuET이 살아난다." — 반대 방향이 관측됨
- ❌ "inner와 outer의 중복이 실패 원인임이 확인됐다." — 예측 미지지, 인과 미확인
- ❌ "DuET과 Complete Nested는 동등하다." — 검출 실패 ≠ 동등성
- ❌ "DuET formulation이 틀렸다." — 이 조건에서 이득 미검출일 뿐, 수학적 정확성과 무관
- ❌ `bestBB`·`TICAmin`·`Qmax`를 K 간 비교에 사용 — 경로 수 의존

쓸 수 있는 표현:

- ✅ "예산 고정·K 축소 조건에서 DuET의 CN 대비 이득은 검출되지 않았다 (|g| ≤ 0.30, CI가 0 포함)."
- ✅ "안쪽 체크포인트의 ESS/M은 M을 8배 늘려도 변하지 않았다 (0.63–0.86)."
- ✅ "바깥 입자 수를 줄이면 validity가 나빠지고 TICA 도달이 사라진다."

### 5.6 다음에 해야 할 것 (우선순위)

| 순위 | 항목 | 내용 | 비용 |
| ---: | --- | --- | --- |
| **1** | **outer update 식 확인** | 코드가 `W ∝ W·Ẑ/ψ(parent)`를 쓰는지 직접 읽기. 인과 주장의 전제 | 0 (코드 리딩) |
| **2** | **D2 측정** | 체크포인트의 clean-endpoint 추정 ↔ 그 입자의 최종 RMSD 상관. 로깅 추가 필요 | ~1 GPU-h |
| **3** | **D3 측정** | 같은 체크포인트에서 분기한 자식들의 최종 구조 분산 (대안 가설 1 직접 검정) | ~1 GPU-h |
| **4** | **TICA reward (H4)** | reward를 `−λ(TICA 거리)²`로. 새 observable 필요. Q를 독립 검증 지표로 고정 | ~2 GPU-h |

"차이 없음"으로 끝난 이유를 모르는 상태에서 reward만 바꾸면, 또 차이가 없을 때
원인을 다시 알 수 없다.
