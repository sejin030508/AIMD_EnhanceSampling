## 1. 실험 설정

### 1.1 Backend — PVB (frozen)

| 항목 | 값 |
| --- | --- |
| 논문 | Pretrained Variational Bridge, ICLR 2026, arXiv:2602.07588 |
| 저장소 | `yaledeus/PVB` @ `c08e5e3c` |
| 모델 | `dyVAE`, 파라미터 9,965,317개, torchmdnet 백본 |
| 학습 | augmented bridge matching |
| 체크포인트 | `pvb_atlas.ckpt` (ATLAS fine-tuned), 39,966,301 B, sha256 `574de9d5…57c1b8` |
| 물리 lag | 100 ps (`physical_lag_in_10ps: 10`) |
| sampler | SDE, σ = 0.2, Markov (직전 프레임만 조건) |
| 출력 | heavy atom (수소 제거) |
| `sde_step` | **20** (공개 기본값 10에서 상향) |
| 학습 중 갱신 | 없음. 전 실험에서 frozen |

`sde_step = 20`을 쓴 이유: DuET의 안쪽 checkpoint는 역과정 진행률에 대응하는 정수
스텝에 놓여야 하는데, `sde_step = 10`이면 진행률 0.90이 마지막 결정론적 스텝에 걸려
분기 폭이 정확히 0.0이 된다. 20에서는 0.25→5, 0.50→10, 0.75→15, 0.90→18로 모두
노이즈가 남은 스텝에 떨어진다 (실행 로그 `checkpoint_audit.json`의
`resolved_reverse_update_steps`로 셀마다 확인 가능).

PLaTITO와 ProTDyn은 후보에서 제외했다. PLaTITO는 결정론적 ODE라 안쪽 시계에서
입자가 갈라지지 않고, CA-only coarse-grained라 backbone RMSD reward를 정의할 수 없다.

### 1.3 Reward (outer potential)

```
log ψ_t = −16 · (d_RMSD(x_t, target) / d₀)²
```

- `d_RMSD`: 공통 N/CA/C 원자에 대한 Kabsch RMSD, 전 잔기 범위
- `reward_coefficient = 16.0`, `program.type = terminal`, `potential_floor = 1e-300`
- 바깥 resampling `systematic`, ESS 임계 0.5 / 안쪽 resampling `systematic`

### 1.4 Validity gate

전 경로의 모든 프레임이 4개 검사를 전부 통과해야 그 경로가 valid로 집계된다
(`whole_path_valid_fraction`).

| 검사 | 기준 |
| --- | --- |
| 좌표 유한성 | 모든 좌표 finite |
| CA 충돌 | 비인접 CA 쌍 ≥ 1.0 Å |
| CA 연결 | 인접 CA ≤ 5.501 Å (품질 임계 4.5 Å) |
| 펩타이드 결합 | C–N ∈ [1.0, 1.7] Å (`enforce_peptide_bond: true`) |

### 1.5 지표 정의

| 컬럼 | 정의 |
| --- | --- |
| `wBB` | `weighted_final_backbone_rmsd_a` — SMC 가중 평균 최종 프레임 backbone RMSD (Å). **reward가 직접 최적화하는 양** |
| `heavy` | `weighted_final_heavy_rmsd_a` — 전 중원자 Kabsch RMSD (Å) |
| `bestBB` | `best_valid_final_backbone_rmsd_a` — valid 경로 중 최소 backbone RMSD (Å) |
| `valid` | `whole_path_valid_fraction` — 전 프레임 통과한 경로 비율 |
| `Qmax` | `q_final_max` — 최종 프레임 native contact Q의 **경로 최댓값** |
| `Qmean` | `q_final_mean` — 최종 프레임 Q의 경로 평균 |
| `Qmax/path` | `q_max_over_path_mean` — 경로별 시계열 최댓값의 평균 |
| `TICAmin` | usable 프레임 전체에서 타깃까지의 **최소** TICA 거리 |
| `hit_any` | `valid_anytime_hit_count` — 경로 전체가 valid이면서 한 프레임이라도 TICA 거리 < 0.75 |
| `hit_fin` | `returned_valid_target_hit_count` — 최종 프레임이 hit인 valid 경로 수 |
| `THP` | `weighted_valid_thp` — 가중 transition path 확률 |

native contact Q 정의: 참조 잔기쌍(최소 중원자 거리 < 4.5 Å, |i−j| ≥ 3)이 참조
거리의 1.2배 이내에 형성된 비율. 성공 조건은 첫 두 backbone-torsion TICA 좌표에서
유클리드 거리 < 0.75.

### 1.6 방법

여섯 baseline 중 세 가지를 실행했다. 셋 다 decoder population budget K·M = **64**로
고정 — 전 셀 `decoder_nfe = 40,960`으로 동일하다.

| 방법 | K | M | 바깥 resampling | 안쪽 resampling | 성격 |
| --- | ---: | ---: | --- | --- | --- |
| Frozen | 64 | 1 | ❌ | ❌ | 독립 rollout 64회. steering 없음 |
| Complete Nested | 8 | 8 | ✅ | ❌ (완성 후 선택) | 전이를 끝까지 만든 뒤 고름 |
| DuET | 8 | 8 | ✅ | ✅ (diffusion 중간) | 완성 전 중간 checkpoint에서 고름 |

Frozen과 Complete Nested는 안쪽 resampling을 하지 않으므로 checkpoint timing에
반응하지 않는다 (둘 다 `denoise_to_checkpoint`를 통과하지만 거기서 아무 일도 하지
않고 동일 시드로 재시딩된다). 그래서 이 둘은 timing 하나(cp7590)에서만 실행했다.

**DuET과 Complete Nested의 유일한 차이는 안쪽 resampling 여부다.** K, M, 예산, 바깥
필터, reward, 시드가 전부 동일하다. 이것이 이 실험의 핵심 대조다.

## 4. 결론과 해석

해석은 다시 수행될 예정이므로 여기서는 **원자료에서 직접 읽히는 것**과
**집계 방식에 의존하는 것**을 구분해 적는다.

### 4.1 집계 방식과 무관하게 성립하는 것

**(1) Steering은 자기 reward 위에서 확실히 작동한다.**
DuET / Complete Nested는 Frozen 대비 wBB를 2.2–3.0 Å 낮춘다. Welch t는
−17 ~ −36 (§2.4)이고, 표준편차가 0.11–0.93로 작다. §3 raw 표에서 셀 단위로도
예외가 없다 — 60개 Frozen 셀의 wBB가 대응하는 DuET/CN 셀보다 전부 높다.

**(2) DuET은 Complete Nested와 구분되지 않는다.**
두 방법은 안쪽 resampling 유무만 다른데, §2.4의 18개 검정(3 단백질 × 6 지표)에서
|t| < 1.5이고 wBB만 보면 |t| ≤ 0.87이다. 이 실험의 핵심 대조에서 **차이가 관측되지
않았다.**

**(3) checkpoint timing 4종은 seed 산포 이내다.**
Trp-cage는 네 timing이 0.03 Å 안에 들어온다 — 표준편차(0.21–0.27)의 약 1/8.
BBA는 0.14 Å 범위. BBL의 `cp255075`만 0.45–0.61 Å 낮으나 표준편차 0.84를 감안하면
경계선이고, 하필 validity가 0.24로 무너진 단백질에서만 나온 신호다.

**(4) BBL만 validity가 붕괴한다 (0.15–0.28), 방법과 무관하게.**
결합당 펩타이드 위반율: Trp-cage 9/195,624 = 0.00005, BBA **0/277,992 = 0.00000**,
BBL 627/473,616 = 0.00132 (최악 C–N 거리 5.76 Å). BBL은 Trp-cage의 26배인데
사슬 길이 비는 2.4배이고, 길이 중간인 BBA는 위반이 0건이다 — 길이가 이 순서를
설명하지 못한다. 출발 구조 Rg 비(§1.2)는 BBL만 2.27로 질적으로 다르며, PVB-ATLAS가
평형 MD에 fine-tune되어 folded/near-folded 분포를 담고 있다는 점과 일치한다.

**(5) K/M 배분은 설명 변수가 아니다.**
K를 2 → 8 → 32로 16배 올려도 wBB는 BBA에서 4.87 / 5.12 / 4.81로 평평하고 hit은
0에서 움직이지 않는다. 반면 steering이 없는 Frozen(K64)은 hit 74건을 낸다.
K2–K32 구간보다 K32–K64 구간의 간격이 훨씬 큰데, 그 구간에서 바뀌는 것은 경로 수가
아니라 steering의 유무다. (단, 보조 블록은 seed 3개다.)

### 4.2 집계 방식에 의존하는 것 — 해석 시 주의

**(6) native contact Q의 방법 순서는 경로 수 정규화에 따라 뒤집힌다.**
`Qmax` 원본으로 보면 Frozen이 세 단백질 모두 1위지만(0.333 / 0.438 / 0.313),
경로 수를 8로 맞추면 **세 단백질 모두 순서가 뒤집혀** Frozen이 최하위가 된다
(0.245 / 0.388 / 0.258). `Qmean`은 애초에 처음부터 steering 팔이 높다
(Trp-cage 0.123 vs 0.182 / 0.170). §2.5 참조.
⇒ "steering이 RMSD만 낮추고 native contact은 악화시킨다"는 진술은 `Qmax` 원본에서만
성립하며, 그 비교는 64경로와 8경로의 최댓값을 맞대는 것이다.

**(7) TICA 타깃 도달의 방법 순서는 timing 합산 여부에 따라 달라진다.**
cp7590만 보면 DuET이 세 단백질 모두 최하위다. hit은 372셀 전체에서 147건으로 매우
희소하고, timing이 다른 지표에 영향을 주지 않으므로(4.1-3) DuET의 네 timing을
동일 과정의 4회 추출로 합쳐 640경로로 재추정하면 **Trp-cage와 BBL에서 DuET이
Frozen보다 높다**. Frozen이 앞서는 것은 BBA 단독이고 z = +2.54인데, 이 보고서가
수행한 9건의 비율 검정에 Bonferroni를 적용하면(α = 0.05/9, z_crit ≈ 2.77) 유의
기준을 넘지 못한다. §2.6 참조.
⇒ "steering 없는 팔만 타깃에 도달한다"는 진술은 BBA 단독 관측이며, 다중비교 후
유의하지 않다. TICAmin은 경로 수를 맞춰도 순서가 유지되지만(§2.5) 격차는 BBA에서
3.0배 → 1.26배로 줄고 BBL은 동률이 된다.

### 4.3 성공률이 오르지 않는 이유 — 분리되지 않는 세 요인

1. **Horizon.** T = 32 × 100 ps = 3.2 ns. fast folder의 folding 시간은 마이크로초
   규모다. 3.2 ns에서 hit이 희소한 것은 예상된 결과이며 그 자체로는 방법에 대한
   정보를 주지 않는다.
2. **Reward 정렬.** RMSD가 2–3 Å 내려가는 동안 Qmean은 0.02–0.06, TICAmin은 사실상
   제자리다. reward가 성공 지표에 거의 연결되어 있지 않다.
3. **검정력.** hit 147건 / 372셀. Trp-cage는 Frozen 1,280경로에서 2건이다.

DuET이 Complete Nested와 구분되지 않는 것(4.1-2)은 2번의 결과일 가능성이 있다.
안쪽 resampling이 고를 수 있는 신호가 reward뿐인데 그 reward가 성공 방향을 가리키지
않는다면, 중간에 고르든 끝에 고르든 같은 곳에 도착한다. 이 경우 관측된 무차이는
**DuET 알고리즘에 대한 기각이 아니라 미판정**이다. 현재 데이터로 1·2·3을 분리할 수
없다.

### 4.4 주장 경계

쓸 수 없는 표현:

- ❌ "DuET이 folding pathway를 복원했다."
- ❌ "RMSD가 낮아졌으므로 folded 상태에 가깝다."
- ❌ "timing이 성능에 영향을 주지 않는다." — 반응하지 않는 지표 위의 sweep은
  아무것도 측정하지 못한다. non-result이지 부정 증거가 아니다.
- ❌ "DuET이 Complete Nested보다 낫다." — |t| < 1.5
- ❌ "native contact Q는 Frozen이 가장 높다." — 경로 수 미정규화 비교 (§4.2-6)
- ❌ "steering 없는 팔만 타깃에 도달한다." — BBA 단독, 다중비교 후 비유의 (§4.2-7)
- ❌ "PVB에서 DuET이 작동하지 않는다." — 검정력 부족 구간, 기각이 아니라 미판정

쓸 수 있는 표현:

- ✅ "동일 예산에서 steering은 reward를 확실히 개선한다 (|t| = 17–36)."
- ✅ "안쪽 resampling의 추가 이득은 20 seed에서 관측되지 않았다 (|t| < 1.5)."
- ✅ "3.2 ns horizon과 RMSD reward 조건에서는 성공 지표가 어떤 조작에도 반응하지 않는다."
- ✅ "BBL의 validity 붕괴는 사슬 길이가 아니라 출발 구조 팽창도와 일치한다."

### 4.5 다음 단계 제안

**H4 — TICA 좌표 기반 reward.** reward를 `−λ·(TICA distance)²`로 바꾸고 BBA에서
DuET K8×M8을 재실행해 기존 Frozen baseline과 비교. config 변경이 아니라 새
observable이 필요하다 (TICA projection이 샘플링 루프 안에서 접근 가능해야 함).
반증 조건: TICA-reward DuET도 hit 0이면 한계는 reward가 아니라 3.2 ns horizon에 있다.

**H4 부속.** DuET이 CN과 구분되지 않는 원인이 "reward가 신호를 주지 않아서"인지
"중간 개입 자체가 무력해서"인지 가르려면, H4 실행 시 checkpoint 개수를
0(= Complete Nested) / 1 / 2로 두고 같은 지표를 비교하면 직접 검정된다.

**H1.** BBL을 Rg ≈ 15 Å 수준의 덜 팽창된 출발 구조에서 재실행. TPS-DPS의 `path.gro`가
없으므로 보간 + Cα 구속 minimization으로 중간 구조를 새로 만들어야 한다.

**권장하지 않음.** reward를 바꾸지 않은 상태의 추가 timing / K-M sweep. 20 seed로
이미 무반응이 확인됐다.
